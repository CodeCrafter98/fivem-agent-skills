# Cursor

**Installation via skills.sh (Recommended):**
```bash
npx skills add CodeCrafter98/fivem-agent-skills --agent cursor
```

Prefer project-local `.agents/skills/` for portability. Cursor currently discovers `.agents/skills/` directly and progressively loads skills based on their descriptions. Keep persistent project-specific rules short; do not duplicate all skill content into Cursor rules (e.g. `.cursorrules`).
